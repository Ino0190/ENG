# 英文法 やり直しドリル

どこから分からなくなったのかを先に見つけて、そこから高校範囲までを登り直すための学習ツール。
スマホで開いて1問ずつ進める前提で作ってある。

公開URL: https://ino0190.github.io/ENG/

- インストール不要。ブラウザだけで動く（外部ライブラリなし）
- 進捗は自分のブラウザに保存される。**どこにも送信しない**
- スマホのホーム画面に追加すればアプリのように開ける

## 画面の作り

**どのページも、開いたときに出るのは「次にやること」1つだけ。** 一覧は畳んである。

- 大きいボタン＝いまやるべきもの。押すとそのまま始まる（どこまで進んだかを見て自動で選ぶ）
- その下の **▸ が付いた行**（文法マップ・ステージを選ぶ・そのほか）は押すと開く一覧
- **右上の ☰** にページ移動・読み上げ・じゅもん・記録の消去が入っている
- ☰ の左の小さい文字が**版**。出ない＝古いファイル

## 5つのページ

| ページ | 役割 |
|---|---|
| `index.html` | **診断**。39単元117問（中1〜高校）。カリキュラム順に見て「最初につまずいた単元」を出す。一度間違えた単元は3問→5問に増える |
| `kanryo.html` | **完了形**。8つの型・40文。診断で崩れの起点になりやすいところ |
| `saigakushu.html` | **再学習**。完了形の次から高校まで。6ステージ・20の型・160文 |
| `bunpo.html` | **解説**。全39単元を文法用語ゼロで説明 |
| `tango.html` | **単語**。レベル別104語（どのレベルから落ちるかを測る）＋**仕事・趣味の分野別60語**＋**語と語の組み合わせ24組** |

## 進め方

1. **診断**（`index.html`）で崩れの起点を出す。各単元3問で全117問。途中でやめても続きから再開できる
2. 起点が完了形なら **完了形**（`kanryo.html`）へ。8つの型を見分けられる状態にする
3. **再学習**（`saigakushu.html`）は「🗣 暗唱セット」から始める。型ごとに代表文が1本だけ（20文）あるので、まず口が回る状態を作る
4. そのあとステージ1→6の順にドリルを回す。カリキュラム順ではなく、前のステージが次の土台になる順に並べてある（ステージ1＝診断で崩れの起点になった「動詞のうしろに来る形」、ステージ6＝伝聞・倒置・強調・物を主語にする言い回し）
5. 分からない言い方が出たら **解説**（`bunpo.html`）を見る。用語を使わずに書いてある

## 仕掛け

- **間違えた型は問題数が増える**。1回でも間違えるとその型に追加の文が解放され、5文から8文になる。間違えたその場で出題数が増える
- **3回連続で正解するまで残る**。間違えた文は数問後に戻ってくる。3回続けて正解すると消える
- **暗唱は差し替え前提**。代表文には「入れ替えて使う」例が付いている。1文覚えて中身を変えれば別の場面で言える
- **語と語の組み合わせは「直訳すると選ぶ方」を誤答に置いてある**（`tango.html` の下段）。文法が合っていても組み合わせを外すと不自然になる帯で、決定を do a decision、〜について discuss about のように、日本語から引っぱると出てくる形を相手にする。日本語だけを見て英語を思い出す一方向の出題
- **AIに例文を頼む文をコピーできる**。型の要点と自分の間違え方を含んだ依頼文が作られるので、ChatGPTやClaudeに貼れば練習用の例文が返ってくる。最後に日本語だけの一覧が付くので、答えを隠して練習できる

## 読み上げ

**答えると、正解の文をそのまま英語で読む。** 目で見るだけより耳に残る。

- 解説の中に **「🔊 もう一度」「🐢 ゆっくり」** がある。聞き取れなかったらここ
- 右上の **☰ → 「🔊 読み上げの設定」** でオン/オフと**声の選び直し**ができる
- 声は端末に入っているものから自動で一番自然なものを選ぶ。気に入らなければ一覧から選び直せる（「▶ 試す」で聞き比べられる）

**もっと自然な声にしたいとき**（iPhone）

```
設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語
```

ここで高品質な声を追加すると、ドリルの設定画面に出てくるので選べる。

本体の消音スイッチがオンだと鳴らないことがある。

## 端末をまたぐとき（ふっかつのじゅもん）

進捗はブラウザごと・URLごとに保存されるので、パソコンとスマホでは別扱いになる。
移すときは 右上の **☰ → 「📜 ふっかつのじゅもん」** を使う（どのページからでも開ける）。
**4ページぜんぶ（診断・完了形・再学習・単語）の記録をまとめて運ぶ。**

### リンクで渡す（おすすめ）

1. 移したい側で **「🔗 復元リンクをコピーする」**
2. 自分宛てに送る（メール・メモアプリ・LINEのKeepなど）
3. もう一方の端末で**そのリンクを開くだけ**。開いた時点で復元される

貼り付ける操作がないので失敗しない。復元したらURLから記録は消える。

### 文字列で渡す

リンクが使えないときは「📜 じゅもんの文字列をコピーする」で渡して、
受け取った側の②に貼り付けて「✨ これで復元する」。

貼り付けた時点で**読めたかどうかが出る**ので、ボタンを押す前に分かる。
改行・全角・前後の文章（「以上」やメールの署名など）が混ざっても読む。
読めないときは理由が出る（途中で切れている／文字が壊れている）。

### どちらの場合も

復元は上書きではなく、**進んでいる方を残す**形で合わせる。両方の端末で進めていても記録は消えない。

## 手元で動かす

ダブルクリックで開くだけで動く。サーバーは不要。

```
open index.html
```

## 更新の流れ

原本は別リポジトリ外のローカル（`KiroProjects/ENG_Drill/`）にあり、ここへは手動でアップロードしている。
問題データを直したら、アップロードの前にデータ検証を通す。

```
node _check.js
```

単元数・問題数・選択肢の数・正解の位置・空所が1箇所か・例文に語形が含まれるか・
型ごとの文数（基本5文と追加3文）・暗唱の代表文が型ごと1本かを、まとめて検査する。

アップロードするファイルは13個。

```
index.html  kanryo.html  kanryo.js  saigakushu.html  saigakushu.js
bunpo.html  tango.html  words.js  questions.js
ver.js  jumon.js  speak.js  menu.js
```

`_check.js` は検証用なので上げなくてよい。

### 版の確認とキャッシュ

全ページの右上（☰ の左）に**版**が出る（`ver.js` の `APP_VER` が正本。直したらここを上げる）。

**うまくいかないときは、まず両方の端末で版を見比べる。**
違っていたら、古い方がまだ届いていないかキャッシュが残っている。

- **版が出ない** → 古いファイル。版表示は新しい版にしか入っていない
- **上げたのに変わらない** → キャッシュ。URLの末尾に `?v=3` のようなクエリを付けて開くと、必ず取り直される

```
https://ino0190.github.io/ENG/saigakushu.html?v=4
```

スマホでホーム画面に追加している場合は、いったん削除して追加し直すと確実。

### 記録が見つからないとき

**じゅもんは「いま開いているページから見える記録」だけを出す。**
記録はページのURLごとに保存され、ブラウザによっては**ファイルを直接開くとページごとに別々**になる
（Safariはそうなる。だから診断に記録があっても再学習のページからは見えないことがある）。

そのため **じゅもんはどのページからでも開ける**。運びたい記録があるページで出すこと。

- 診断の結果を運ぶ → **診断のページ**（`index.html`）で開いて出す
- 再学習の進捗を運ぶ → **再学習のページ**で出す
- 両方運ぶ → それぞれのページで出して、2回送る

じゅもん画面には**いま開いているページのURLと、そこに入っている記録の一覧**が出る。
0件なら**出す前に警告が出る**ので、空のまま送ることはない。

記録が1か所にまとまっているとき（公開URLで使っている場合など）は、1回で全部運べる。

### リポジトリ名を変えたとき

復元リンクは公開URLを組み立てて作るので、`ver.js` の `PAGES_BASE` を直す。
ここが古いままだと、パソコンで作ったリンクがスマホで404になる。
じゅもん画面の①に**実際の宛先URLが表示される**ので、そこで確かめられる。
